# Build history

Working documents from the build, kept because they record *why* decisions were made. They are
not documentation and are not maintained — read `../verification.md` and `../development.md`
instead, and the tool docs under `core/` for how anything actually works.

- `specs/` — design documents written before each stage
- `plans/` — the execution plans those specs turned into
- `research/` — raw research output on each tool's config surface, in JSON

Anything here may describe behaviour that has since changed. MCP migration, for example, is
discussed at length across these files and was later removed from the tool entirely.
